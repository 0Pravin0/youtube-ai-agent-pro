# Changelog

All notable changes. Versions follow [Semantic Versioning](https://semver.org): MAJOR.MINOR.PATCH.

## 1.0.0

First release for Apple Silicon Macs (M1 and newer).

- Email-first Google sign-in, channel selection, live channel info and 28-day analytics.
- FREE ONLY production by default: local writer (Ollama + Gemma 4), local images (ComfyUI + Stable Diffusion 1.5/SDXL
  on the Apple GPU), local Tamil voice (Indic Parler-TTS), FFmpeg animation and editing — ₹0 per video.
- Approved, checksum-verified installs of every free tool and model; ECO / BALANCED / HIGH QUALITY modes that pause
  work on low battery, heat or memory pressure.
- MCP Connections: built-in read-only media and story tools, remote servers only with per-tool approval, audit log.
- Private-first publishing; autonomous publishing only after explicit authorization.
- Signed in-app updates with automatic backups and versioned database migrations.
